FILE 5: Jenkinsfile  (The Complete CI/CD Pipeline Definition)
=================================================================

LINE 1:  pipeline {
         → "Start of the Declarative Pipeline block.
            Everything inside here defines the CI/CD workflow."

LINE 2:  agent any
         → "Run this pipeline on ANY available Jenkins agent/executor.
            In our case, it runs on the Jenkins container itself."

LINE 4-10: environment { ... }
         → "Define pipeline-level environment variables (like constants):
            DEPLOY_DIR → Path where app will be deployed
            APP_PORT   → Port 5050 that Flask runs on
            APP_PID    → File that stores the Flask process ID
            APP_LOG    → File that stores the Flask server log"

--- STAGE 1: Build ---
LINE 14: stage('Build') {
         → "First stage: Install all dependencies."

LINE 17: sh 'python3 -m pip install --upgrade pip --quiet'
         → "Upgrade pip to the latest version silently."

LINE 18: sh 'pip3 install -r requirements.txt --quiet'
         → "Install all pinned libraries from requirements.txt."

LINE 19: sh 'pip3 show flask | grep Version'
         → "Print the installed Flask version — proves it was installed."

--- STAGE 2: Test ---
LINE 28: stage('Test') {
         → "Second stage: Run automated unit tests."

LINE 31: sh 'python3 -m pytest test_app.py -v --tb=short'
         → "Run pytest on test_app.py:
            -v       → verbose output (shows each test name)
            --tb=short → show short error trace if a test fails
            If ANY test fails, pytest exits with code 1,
            Jenkins detects this and marks stage as FAILED."

--- STAGE 3: Deploy ---
LINE 38: stage('Deploy') {
         → "Third stage: Copy app files to deployment directory."

LINE 41: sh 'mkdir -p ${DEPLOY_DIR}'
         → "Create the deployed-app folder if it doesn't exist."

LINE 42: sh 'cp ${WORKSPACE}/app.py ${DEPLOY_DIR}/'
         → "Copy the Flask app file to the deployment directory."

LINE 44: sh 'ls -la ${DEPLOY_DIR}/'
         → "List the deployment directory to confirm files are there."

--- STAGE 4: Run Application ---
LINE 51: stage('Run Application') {
         → "Fourth stage: Start the Flask server in background."

LINE 54: sh 'pkill -f "python3.*app.py" || true'
         → "Kill any old Flask process from a previous build.
            '|| true' means: if no process found, don't error out."

LINE 57: sh 'nohup python3 ${DEPLOY_DIR}/app.py > ${APP_LOG} 2>&1 &'
         → "Start Flask server:
            nohup     → Don't stop it when this shell session ends
            &         → Run in background (non-blocking)
            > app.log → Write output to log file
            2>&1      → Also write errors to the same log"

LINE 58: sh 'echo $! > ${APP_PID}'
         → "$! is the PID (Process ID) of the last background command.
            Save it to a file so we can stop it later."

LINE 60: sh 'sleep 3'
         → "Wait 3 seconds to give Flask time to fully start up."

--- STAGE 5: Test Application ---
LINE 69: stage('Test Application') {
         → "Fifth stage: Verify the deployed app is running correctly."

LINE 72: sh 'RESPONSE=$(curl -s --max-time 5 http://localhost:${APP_PORT}/)'
         → "Send a live HTTP GET request to the deployed Flask app
            and store the response text in RESPONSE variable."

LINE 73: sh 'HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" ...)'
         → "Get only the HTTP status code (200, 404, 500, etc.)
            -o /dev/null → Discard the body
            -w %{http_code} → Print only the status code"

LINE 77: if [ "${HTTP_CODE}" != "200" ]; then exit 1; fi
         → "If status code is not 200, fail the pipeline.
            exit 1 tells Jenkins: this step FAILED."

LINE 83: if [ "${RESPONSE}" != "${EXPECTED}" ]; then exit 1; fi
         → "If the response body doesn't match exactly, fail the pipeline."

LINE 87: sh 'kill ${PID}'
         → "Stop the Flask server process after verification is done."

--- POST ACTIONS ---
LINE 94: post {
         → "Actions to run AFTER all stages complete."

LINE 95: success { echo "PIPELINE STATUS: SUCCESS" }
         → "If ALL stages passed, print success message."

LINE 103: failure { echo "PIPELINE STATUS: FAILURE" }
         → "If ANY stage failed, print failure message and show the app log."

LINE 112: always { sh 'pkill -f "python3.*app.py" || true' }
         → "ALWAYS runs (success or failure): Kill any remaining Flask process
            to clean up the Jenkins agent. No zombie processes left behind."

WHAT THE Jenkinsfile DOES AS A WHOLE:
  → Defines a 5-stage automated CI/CD workflow:
    Stage 1 (Build)   → Install dependencies
    Stage 2 (Test)    → Run pytest unit tests (GATE: fail here = no deploy)
    Stage 3 (Deploy)  → Copy app to deployment folder
    Stage 4 (Run)     → Start Flask server on port 5050
    Stage 5 (Verify)  → HTTP curl test proves the deployment works
    Post (always)     → Clean up background processes
