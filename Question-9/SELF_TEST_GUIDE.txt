PHASE 3: START JENKINS USING DOCKER DESKTOP
====================================================================

--- Make sure Docker Desktop is running ---
# Check the whale icon in taskbar is solid (not spinning)

--- Step 1: Open PowerShell and start Jenkins container ---
docker run -d --name jenkins `
  -p 8081:8080 `
  -v jenkins_home:/var/jenkins_home `
  jenkins/jenkins:lts

NOTE: In PowerShell, use backtick ` for line continuation (not \)
OR just paste as one line:
docker run -d --name jenkins -p 8081:8080 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts

--- Step 2: Wait 30 seconds for Jenkins to start ---
Start-Sleep -Seconds 30

--- Step 3: Get admin password ---
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword

# Copy the long password shown (like: 53c92dc0dfd24bd09bf0c495857ecebd)

--- Step 4: Open Chrome → http://localhost:8081 ---
# Paste the password → Click Continue
# Click "Install suggested plugins" → Wait for it to finish
# Create admin user → Click "Start using Jenkins"

--- Step 5: Install Python inside Jenkins container ---
# Run this command in PowerShell:
docker exec -u root -it jenkins bash

# You are now INSIDE the Jenkins container (Linux terminal appears)
# Run these one by one:
apt-get update -qq
apt-get install -y python3 python3-pip curl
exit

# You are back in Windows PowerShell now

--- Step 6: Verify Python is inside Jenkins ---
docker exec jenkins python3 --version
docker exec jenkins pip3 --version
docker exec jenkins curl --version
# All 3 must show version numbers!

====================================================================
QUICK REFERENCE: Useful PowerShell Commands
====================================================================

Check Jenkins container is running:
  docker ps --filter name=jenkins

See Jenkins logs:
  docker logs jenkins

Stop Jenkins:
  docker stop jenkins

Start Jenkins again:
  docker start jenkins

Remove Jenkins container completely (fresh start):
  docker rm -f jenkins
  docker run -d --name jenkins -p 8081:8080 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts

Check if port 5050 is in use:
  netstat -ano | findstr :5050
